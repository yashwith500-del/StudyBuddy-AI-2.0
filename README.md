# StudyBuddy AI 2.0

An AI-powered study assistant designed to help students learn smarter, organize their studies, and test their knowledge.

## 🚀 Features

- **AI Tutor:** Get explanations and answers to study questions.
- **Smart Notes:** Generate organized study notes from topics.
- **Quiz Generator:** Create multiple-choice quizzes and track quiz history.
- **Study Planner:** Organize tasks and monitor study progress.
- **Flashcards:** Create, review, and manage question-and-answer cards.
- **User Authentication:** Create accounts, log in, and log out.
- **Cloud Storage:** Save personal study data using Firebase Firestore.
- **Account Isolation:** Keep each user's study information separate.
- **Responsive Design:** Access the application on desktop and mobile devices.

## 🛠️ Technologies Used

- HTML5

## ⚙️ Setup Instructions

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Configure your Firebase project in `firebase.js`.
4. Enable Email/Password authentication in Firebase.
5. Create a Firestore database.
6. Configure Firebase App Check.
7. Configure the AI service used by the project.
8. Run the website using the VS Code Live Server extension.

## 🔐 Security

- Firebase Authentication manages user accounts.
- Firestore security rules restrict users to their own data.
- Firebase App Check helps protect supported Firebase services.
- User study data is stored under individual Firebase user IDs.

The objective of StudyBuddy AI is to create a centralized learning platform that combines AI-powered assistance, personalized study organization, and interactive learning tools.
